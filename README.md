# GTAGMovementKit

A full Gorilla Tag-inspired movement system for Roblox, designed to replicate the original game's movement as closely as possible.

## Features

- Gorilla Tag-style movement
- In-game computer
- Multiple gamemodes
- Cosmetics system

## Installation

1. Download the `.rbxm` file from this repository.
2. Open your game in Roblox Studio.
3. In the Explorer, right-click `Workspace`.
4. Select **Insert from File**.
5. Select the downloaded `.rbxm` file.
6. Place the required scripts, models, and assets into their correct folders.
7. Make sure everything is set up correctly, then press **Play** to test the game.

## Setup

- Make sure all files are in their intended folders.
- Do not rename required objects unless you also update the scripts that reference them.
- Check the Roblox Studio Output window if you encounter any errors.
